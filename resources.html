Scope and method

Operating software requires infrastructure that a team either runs itself or rents. For a small collective, the price of that infrastructure is frequently the first thing that decides what can be built, and a permanent free tier is what makes a serious side project possible.

This page lists services that offer such a tier and are useful to engineers who build, ship and operate software — the system-administration and infrastructure side of the craft that Baseline practises. Each section opens with a short account of the category and then names a handful of services, with the free-tier limit stated as the vendor states it.

The material is derived from free-for.dev, a community-maintained catalogue of free developer tiers, and reflects that source as retrieved on 16 November 2026. Only as-a-service offerings are included; self-hosted software is out of scope by the source's own rule.

Source code hosting

Source code hosting is the storage of version-controlled code on a remote server, where a distributed team can collaborate, review proposed changes and run automated checks against them. Contemporary hosts bundle far more than storage: continuous integration, package and container registries, static-site publishing and issue tracking are commonly included in the free tier, which makes the host a project's centre of gravity rather than a place code merely rests.

  • GitHub Unlimited public and private repositories with unlimited collaborators; includes CI/CD, hosted development environments, static hosting, package and container registries, project management and an AI coding assistant.
  • GitLab Unlimited public and private repositories with up to five collaborators; includes CI/CD, static hosting, a container registry, project management and issue tracking.
  • Codeberg Unlimited public and private repositories with unlimited collaborators for free and open-source projects; runs on Forgejo, and adds Pages, CI, package and container hosting, and issue tracking.
  • Bitbucket Unlimited public and private Git repositories for up to five users, with Pipelines for CI/CD.
  • GitGud Unlimited private and public repositories, free permanently; adds CI/CD, static hosting, a container registry, project management and issue tracking.

Continuous integration and delivery

Continuous integration is the practice of merging every change into a shared branch, where an automated pipeline builds it and runs its tests; continuous delivery extends that pipeline so a passing change can be released without manual assembly. Together they replace the error-prone bundle of manual steps that otherwise separates a commit from a deploy. Free tiers for these services are usually metered in build minutes, concurrent jobs or team seats.

  • CircleCI Free for up to 6,000 execution minutes per month with unlimited collaborators and 30 parallel jobs in private projects; up to 80,000 build minutes for open-source projects. Supports Docker, Windows, macOS and ARM executors.
  • Buildkite CI pipelines free for three users and 5,000 job minutes per month; the developer test-analytics tier adds 100,000 test executions per month.
  • Codemagic 500 build minutes per month free, aimed at mobile build and release automation.
  • AppVeyor Continuous delivery for Windows, free for open-source projects.
  • Trigger.dev Background jobs and AI-agent tasks with durable, no-timeout execution; the free plan carries $5 of monthly compute, 20 concurrent runs, five team members and ten schedules.
  • Nx Cloud Remote caching and task distribution for monorepos, free for up to 30 contributors with 150,000 credits included.

Testing and quality assurance

Automated testing covers the range from unit tests that pin a function's behaviour to end-to-end tests that drive a real browser and visual-regression tests that compare rendered output against an approved baseline. Hosted testing services supply the runners, dashboards and saved snapshots that a single machine cannot reasonably hold, and many of them are free without qualification for open-source work.

  • Cypress The test runner is free and open-source with no restrictions; the dashboard is free for open-source projects of up to five users.
  • Percy Visual testing for web apps, style guides and component libraries; unlimited team members and projects with 5,000 snapshots per month.
  • Argos Open-source visual testing with unlimited projects and 5,000 screenshots per month.
  • Lost Pixel Visual regression testing for Storybook, Ladle and Histoire; 7,000 snapshots per month, free for open-source with unlimited team members.
  • webhook.site A temporary URL and email address for inspecting outbound HTTP requests and webhooks; always free.
  • Qase Test-case management with the core features in the free tier, 500 MB of attachment storage and up to three users.

Code quality and review

Code quality tooling inspects a change and reports the defects that a reviewer would otherwise have to find by hand — coverage gaps, duplicated logic, unsafe dependencies, style drift. Applied through a repository's integration, it comments on each pull request before a human looks, which is where it earns its keep. Almost all of these services are free for public repositories without a limit on how many are scanned.

  • Codacy Automated review for a wide range of languages, free for unlimited public and private repositories.
  • Codecov Test-coverage reporting, free for open-source projects plus one private repository.
  • CodeRabbit AI-assisted pull-request review, free permanently for open source; the free tier runs 200 files per hour and three reviews per hour.
  • CodeFactor Automated review for Git repositories; unlimited users and public repositories plus one private repository.
  • DeepSource Continuous analysis for security, performance and bug-risk issues, integrated with GitHub, GitLab and Bitbucket.
  • Shields.io Quality-metadata badges for open-source projects — the small images that report build, coverage and version at a glance.

Security and certificates

Application security covers the exposure of secrets, the freshness of transport certificates and the provenance of dependencies. A certificate authority issues the TLS certificates that encrypt traffic; scanners then check the configuration that carries them, and secret-scanning and supply-chain tools watch for credentials and malicious packages entering a repository. The tooling that protects a small project is, in the main, free.

  • Let's Encrypt A free certificate authority issuing TLS certificates trusted by all major browsers, which underpins encrypted transport for most of the open web.
  • GitGuardian Automated detection of secrets and sensitive files in Git repositories, scanning for more than 350 types; free for individuals and teams of up to 25 developers.
  • Socket Supply-chain security that flags vulnerable and malicious dependencies; free for individual developers, small teams and open-source projects.
  • Mozilla Observatory Scans a site's configuration and reports the security headers and settings it should fix.
  • Internet.nl Tests a domain against modern Internet standards including IPv6, DNSSEC, HTTPS, DMARC, STARTTLS and DANE.
  • Have I Been Pwned A REST API for checking whether an address appears in known data breaches.

Monitoring and uptime

Monitoring is the continuous observation of a running system to detect failure before a user reports it. Uptime monitoring answers the narrowest and most important question — is the service reachable — while metrics, alerting and status pages add the context needed to act on the answer. These services typically charge by the number of monitors and the frequency at which each is checked; the free tiers are generous enough for a portfolio of small projects.

  • UptimeRobot Fifty monitors with five-minute check intervals, supporting HTTP, ping, port and keyword checks.
  • Better Stack Ten monitors at three-minute frequency, with incident management, on-call scheduling and status pages in the same product.
  • Pingzen Up to 55 uptime and API monitors with one-minute check intervals and instant alerts.
  • Healthchecks.io Dead-man's-switch monitoring for cron jobs and background tasks; free for up to 20 checks.
  • Cronitor Uptime and cron monitoring for jobs, websites and APIs, with a free tier of five monitors.
  • Grafana Cloud A composable observability stack free for three users and ten dashboards, with 100 alerts, 10,000 metric series and 50 GB of logs at 14-day retention.

Logging and error tracking

Logs are the chronological record of what a system did; error tracking is a focused form of the same idea that groups exceptions by cause and reports how often each one occurs. Both matter most in production, where a stack trace without the surrounding context is nearly useless. Free tiers for these services are measured in ingested events or bytes held, and several of the tools can be self-hosted without limit.

  • Sentry Real-time exception tracking, free for 5,000 errors per month and one user; unrestricted if self-hosted.
  • GlitchTip Open-source error tracking compatible with the Sentry SDKs; 1,000 events per month free, or unlimited when self-hosted.
  • Rollbar Error and exception monitoring with a free plan of 5,000 errors per month, unlimited users and 30-day retention.
  • Axiom Log storage of up to 0.5 TB with 30-day retention and integrations for platforms such as Vercel.
  • New Relic Observability for the whole stack with 100 GB of data ingest per month, one full-access user and unlimited primary users.
  • Middleware.io Infrastructure monitoring and application performance monitoring for up to two hosts, with log monitoring for up to a million events per month.

Application hosting

Application hosting is the platform that builds a repository and serves the result on the public Internet. The category spans static-site hosting, which publishes pre-rendered files to a content delivery network, and platform-as-a-service offerings, which run a long-lived application process and attach a database behind it. Free tiers are usually expressed in bandwidth, build minutes or compute hours, and frequently allow a custom domain with automatic TLS.

  • Vercel Builds, deploys and hosts web applications with free TLS, a global CDN and a unique preview URL for every push.
  • Netlify Free for 300 credits per month, which the vendor equates to 30 GB of bandwidth.
  • Cloudflare Pages Five hundred builds per month, 100 custom domains, integrated TLS, unlimited seats and unlimited preview deployments, with full-stack capability through Workers.
  • Render A unified cloud with free TLS, a global CDN and auto-deploys from Git; web services, databases and static pages each have a free plan.
  • Koyeb A serverless platform whose free hobby plan provides 550 compute hours per month at 512 MB of memory, one PostgreSQL database and custom-domain TLS.
  • Northflank Builds and runs containers, jobs and managed databases; the free tier includes two services, two cron jobs and one database.

Backend as a service

A backend as a service supplies the server-side half of an application — a database, authentication, file storage and functions — behind an API that the client calls directly. The model removes the need to operate a server for projects whose logic is thin, and it suits prototypes and small products particularly well. Free tiers are measured in stored records, monthly function calls and active users.

  • Supabase An open-source alternative to Firebase built on PostgreSQL; the free plan offers authentication, a realtime database and object storage.
  • Appwrite Unlimited projects with no pausing and WebSocket support; each project's free tier includes one database, three buckets and five functions.
  • Convex A reactive backend hosting documents with relationships and ACID transactions, serverless functions and WebSocket streaming; free for up to a million records and five million monthly function calls.
  • Nhost A serverless backend whose free plan includes PostgreSQL, GraphQL through Hasura, authentication, storage and serverless functions.
  • Back4App A flexible backend built on the open-source Parse platform.
  • Pusher Beams Unlimited push notifications for up to 2,000 monthly active users from a single API for iOS and Android.

Managed data services

A managed database is one whose host handles provisioning, backups, patching and failover, leaving the developer only the schema and the queries. Managed offerings exist for the relational, document, key-value, graph and vector models, and the relational and key-value tiers are the ones most often free without a time limit. Limits here are stated in storage, monthly operations or compute-hour allowances, and the smallest tiers pause when idle.

  • Neon Serverless PostgreSQL with 0.5 GB of storage per project across 100 projects, ten branches per project, 100 compute-unit hours per month and scale-to-zero after five minutes idle.
  • Turso SQLite at the edge with a permanent free plan of 9 GB total storage, up to 500 databases, three locations and a billion row reads per month.
  • Upstash Serverless Redis free up to 500,000 commands per month, with a 256 MB maximum database size and 20 concurrent connections.
  • Prisma Postgres Hosted PostgreSQL 17 with no cold starts; the free plan includes 1.01 GB of storage, 200,000 operations per month and 50 databases.
  • Aiven Free single-node PostgreSQL, MySQL and Valkey plans with one CPU, 1 GB of memory and, for the relational engines, 1 GB of storage.
  • Qdrant A vector database for embedding data, free at a single node with 0.5 vCPU, 1 GB of memory and 4 GB of disk.

Content delivery and DNS

A content delivery network caches files at points of presence around the world so that a request is answered from a location near the visitor rather than from the origin server. The domain name system is the look-up layer that turns a name into an address, and the two are commonly operated together behind one edge provider that also filters hostile traffic. The tiers that make this free to a small site are among the most valuable on this page.

  • Cloudflare Free DNS for unlimited domains with DDoS protection, a CDN and TLS, firewall and page rules, a web application firewall, bot mitigation, rate limiting and analytics.
  • Cloudflare Workers Serverless functions on the same global network, free for 100,000 requests per day; the companion R2 store offers 10 GB per month and D1 offers a 1 GB SQLite database with five million row reads per day.
  • jsDelivr A free open-source CDN serving packages from npm, GitHub, WordPress and Deno.
  • Gcore A global CDN free for 1 TB and one million requests per month, with DNS hosting included.
  • deSEC Free DNS hosting with API support, built on open-source software with security as an explicit design goal.
  • 1.1.1.1 A free public DNS resolver that encrypts queries, useful for bypassing provider-level blocking and query logging. It resolves names; it does not host zones.

Transactional email

Transactional email is the automated mail an application sends in response to an event — a sign-up confirmation, a password reset, a receipt — as distinct from bulk marketing. Delivering it reliably requires an authenticated sending domain configured with SPF, DKIM and DMARC, so the mail is not rejected as spoofed. Free tiers are counted in monthly messages, usually with a lower daily ceiling.

  • Resend A transactional email API free for 3,000 messages per month and 100 per day, with one custom domain.
  • Brevo Free for 9,000 emails per month and 300 per day.
  • Mailjet Free for 6,000 emails per month, with a daily sending limit of 200.
  • MailerSend Email API and SMTP free for 500 transactional emails per month and 100 API requests per day.
  • Postmark Free for 100 emails per month, with unlimited weekly DMARC digests.
  • Mailtrap Free for 4,000 emails per month and 150 per day; its sandbox captures 50 test emails per month so sending can be verified without delivery.

Authentication and authorization

Authentication establishes who a user is; authorization decides what that user may do. Both are areas where a home-grown implementation is a liability, and where a mistake is a breach rather than a bug. Hosted identity services provide sign-in, multi-factor authentication, social-login and, increasingly, fine-grained permission models behind an SDK, and price the free tier by monthly active users.

  • Clerk User management, authentication, MFA and prebuilt sign-in components; free for unlimited applications with 50,000 monthly retained users per app and three dashboard seats.
  • Auth0 Hosted single sign-on free for 25,000 monthly active users, with unlimited social connections and a custom domain.
  • WorkOS User management and authentication free for up to one million monthly active users, including email and password, social login, magic auth and MFA.
  • SuperTokens Open-source authentication that integrates into an application directly; free for up to 5,000 monthly active users.
  • Logto Identity for authentication and authorization, free for up to 5,000 monthly active users with a self-hosted option.
  • ZITADEL Cloud Turnkey user and access management for multi-tenant applications, free for up to 25,000 authenticated requests with passwordless and one-time-password support.

Storage and media

Object storage holds files as immutable blobs addressed by key, the model underlying most image, video and document delivery. A related class of services adds transformation — resizing an image, transcoding a video — at the point of delivery, so a single stored original can be served at any size. Free tiers are counted in stored bytes, delivery bandwidth or transformation credits, and several reserve their most generous terms for open-source projects.

  • Cloudflare R2 S3-compatible object storage free for 10 GB per month, with one million Class A and ten million Class B operations per month.
  • Backblaze B2 S3-like object storage free for 10 GB, with no expiry.
  • Cloudinary Image upload, transformation and delivery with 25 monthly credits, where one credit is 1,000 transformations, 1 GB of storage or 1 GB of delivery.
  • ImageKit An image CDN with automatic optimization and real-time transformation, free up to 20 GB of bandwidth per month.
  • Gumlet Image and video hosting, processing and streaming, with 250 GB per month of video and 30 GB per month of image delivery free.
  • Pinata Pinning and management of files on the InterPlanetary File System, free for 1 GB of storage with API access.

Generative AI and machine learning

Generative models produce text, images or code from a prompt, and the tooling around them covers training, evaluation and observability. For an engineer the practical free tiers fall into two groups: inference — access to a hosted model — and the operations layer that traces, evaluates and monitors a model-backed application. Free inference is nearly always rate-limited rather than billed, so it suits experimentation and light production rather than sustained load.

  • OpenRouter A single API across many models, several of them free, including DeepSeek and Llama variants; the free models are subject to rate limits.
  • Google AI Studio Free access to the Gemini and Gemma model families; the free Flash tier allows five requests per minute and 20 per day at up to 250,000 input tokens per minute.
  • Pollinations.AI Free image generation with a public API that requires no account or key.
  • Langfuse Open-source LLM engineering for debugging and iterating on model-backed applications; free permanently for 50,000 observations per month with all features.
  • Weights & Biases Experiment tracking, dataset versioning and model management, free for personal projects with 100 GB of storage.
  • Arize AX Observability and evaluation for AI applications, free for unlimited users and evaluations with 25,000 spans and 1 GB of ingestion per month.

Issue tracking and project management

Issue tracking records the work a team intends to do and the state each item is in, and project management adds the boards, documents and diagrams around it. For a small collective the value is chiefly in having one place where a decision, a task and its owner are written down, rather than distributed across chat. Free plans in this category are usually limited by seat count or by the number of active items.

  • Linear A streamlined issue tracker, free for unlimited members with up to 250 issues and 10 MB file uploads.
  • Jira Software project management free for up to ten users.
  • ClickUp Project management with a free tier that includes cloud storage, mobile applications and Git integrations.
  • Basecamp To-do lists, milestones, messages and file sharing for up to three projects, 20 users and 1 GB of storage.
  • diagrams.net Online diagrams stored locally in Google Drive, OneDrive or Dropbox; all features are free at every storage level.
  • Cloudcraft A visual designer for cloud architecture diagrams, free for unlimited private diagrams for a single user.

Caveats and sources

The limits on this page are transcribed, not estimated. Each figure is the free-tier allowance that free-for.dev recorded as of 16 November 2026, and the vendors themselves are the authority on their own terms — a tier can change, and the pricing page is what governs. Where a service sleeps when idle, pauses after inactivity, or restricts a free plan to one project or one user, that constraint is part of the offer and is named above where the source states it.

The list is intentionally partial. It covers the categories that matter most to engineers building and operating software, which is the work Baseline is built around; the source covers further ground still — analytics, forms, fonts, translation, visitor recording and more — and should be consulted directly for anything outside the scope here. Free-for.dev is a community project maintained by its contributors; this page restates its facts in prose and credits it as the origin.
